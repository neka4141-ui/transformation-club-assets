## Готовый код для GetPlatinum — файлы уже на GitHub

1. Откройте `getplatinum-embed.html` в редакторе и скопируйте **весь код**.
2. В GetPlatinum замените содержимое прежнего HTML-блока этим кодом целиком. Не добавляйте вторую копию блока рядом со старой.
3. Сохраните и опубликуйте страницу. Проверяйте опубликованную страницу: редактор конструктора может не исполнять JavaScript.

Дополнительная загрузка картинок или шрифтов в конструктор не нужна. CSS и JS встроены в код, изображения и шрифты загружаются по публичным HTTPS-ссылкам GitHub. Стили ограничены контейнером `#tc-embed`, чтобы меньше зависеть от оформления конструктора.

`index-online.html` — полноценный HTML-документ с теми же удалёнными файлами: для конструктора, который принимает файл целиком, и для просмотра двойным щелчком. Для обеих онлайн-версий нужен интернет.

Репозиторий: https://github.com/neka4141-ui/transformation-club-assets/tree/main/site-v1

Адреса изображений закреплены за коммитом `0dd0e4ebf806670fe65187011c4ae860f1f1fc1f`. Старые `1.PNG`–`7.PNG` в корне репозитория сохранены. Не делайте репозиторий приватным: публичные ссылки перестанут работать.

В **онлайн-версиях** четыре адреса оплаты/записи/видео редактируются непосредственно в HTML, в строке `const links = { light: '', master: '', personal: '', video: '' };`. В исходной автономной версии `index.html` они по-прежнему находятся в `assets/config.js`. Реальных адресов исходный сайт не содержал.

`build_embed.py` пересобирает оба онлайн-файла из локальной версии. После изменения онлайн-HTML вручную повторная сборка перезапишет ручные правки.

Онлайн-документ и HTML-блок в сохранённой оболочке GetPlatinum проверены при ширинах 390 и 1440 px, без горизонтального переполнения; диалог открывается и закрывается клавишей Escape. Проверка проводилась локально, опубликованная страница GetPlatinum не изменялась. В локальной оболочке не загрузились три сторонних шрифта самого конструктора; собственные шрифты сайта загрузились успешно.

## Исходная версия для работы без интернета

Откройте `index.html` двойным щелчком. Установка Node.js, сборка и интернет для просмотра не нужны. Для публикации загрузите `index.html` и папку `assets` на любой статический хостинг, сохранив структуру.

## Что внутри

- `index.html` — семь блоков оригинала, включая footer; весь текст редактируется здесь.
- `assets/styles.css` — адаптивная вёрстка, отдельные карточки, телефон, золотые кнопки и анимации.
- `assets/app.js` — появление элементов при прокрутке, обработка кнопок и доступное диалоговое окно.
- `assets/config.js` — четыре адреса оплаты, записи и видео.
- `assets/backgrounds/01…07.png` — семь восстановленных фонов в полном разрешении, без встроенного текста и кнопок.
- `assets/backgrounds/01…07.webp` — оптимизированные изображения, используемые сайтом (всего около 650 КБ).
- `assets/fonts` — локальные Montserrat и Caveat с лицензиями OFL.
- `reference` — оригиналы семи PNG, сохранённый HTML, промпты и материалы проверки; для публикации не требуется.

## Подключение кнопок

На исходной странице ссылки оплаты, записи и видео равны `#`. Реальных адресов там нет. Укажите полные HTTPS-адреса в `assets/config.js`:

```js
window.CLUB_LINKS = Object.freeze({
  light: 'https://ваш-домен/оплата-старт',
  master: 'https://ваш-домен/оплата-мастер',
  personal: 'https://t.me/ваш_аккаунт',
  video: 'https://ваш-домен/видео'
});
```

До заполнения адресов кнопки показывают честное сообщение о недоступности. Оплата, Telegram-бот и видео не имитируются. После заполнения кнопки открывают указанные адреса в текущей вкладке. При отключённом JavaScript доступны весь контент, навигация и текстовый fallback; подключённые через config.js адреса требуют JavaScript.

## Визуальное соответствие

Сохранены порядок, тексты тарифов и реквизитов, цены, чёрно-золотая палитра, сюжет фотографий и композиция исходника. Фоны восстановлены встроенным imagegen отдельно для каждого исходного PNG. Это генеративная реконструкция: детали фотографий под удалёнными надписями могут отличаться от оригинала. Шрифты подобраны визуально (исходные шрифтовые файлы на странице отсутствуют).

Текст, цены, кнопки, рамки карточек и телефон — HTML/CSS. Фотографии и фактура — отдельные растровые фоны. Сообщение внутри телефона является примером, скрытая персональная ссылка не выдумывается. На мобильных экранах высота карточек зависит от текста, поэтому пропорции длинных исходных PNG намеренно не фиксируются.

Анимации: спокойное появление первого экрана, однократный fade/translate при прокрутке, мягкий hover/press кнопок. Нет бесконечного параллакса и обработчика каждого события scroll. Учитывается `prefers-reduced-motion`; без JS контент остаётся видимым.

## Уточнение вёрстки по референсам

- Сверху закреплена полупрозрачная тёмная панель: «Главная», «Тарифы», «Смотреть про клуб». Это HTML/CSS, все пункты доступны мышью, касанием и клавиатурой. Переходы учитывают высоту панели. Текущий раздел подсвечивается при прокрутке.
- Подпись «и клуб трансформаций» поднята ближе к заголовку; Neucha, мягкое затемнение и тень сохраняют контраст. В заголовке запрещён разрыв фразы «3-Х ШАГОВ».
- Второй экран сохраняет четыре строки: три жирные и отдельную обычную подпись «к системе и клубу». Переносы не удаляются на телефоне. Телефон увеличен относительно прежней мобильной версии и слегка наклонён.
- Все три тарифа находятся в CSS Grid с одинаковой высотой строк. У «Лёгкого старта» сохранено свободное место до нижней кнопки, как в референсе. Минимальная высота зависит от ширины, а более длинный текст может увеличить все три блока одинаково.
- Карточки занимают 75% ширины секции, включая мобильную версию; внутренние отступы текста также пропорциональны референсу.
- Фотографии масштабируются только равномерно: `background-size: 100% auto`, без растяжения по двум независимым осям. В индивидуальном тарифе фотография привязана к нижнему краю.
- Тап-отклик сохранён: лёгкое нажатие и световая волна. Отмена касания сбрасывает эффект; reduced motion отключает движение.

Проверено в сохранённой оболочке GetPlatinum при 320, 390, 768 и 1440 px: нет горизонтального переполнения, все четыре строки второго экрана помещаются, высоты тарифов равны, ширина каждой карточки 75%, панель остаётся у верхнего края окна. Проверены три перехода меню, открытие и закрытие диалога оплаты; ошибок JavaScript нет. Скриншоты — `reference/layout-final-*`.
