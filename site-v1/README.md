# Система 3-х шагов — самостоятельный HTML-сайт

Откройте `index.html` двойным щелчком. Установка Node.js, сборка и интернет для просмотра не нужны. Для публикации загрузите `index.html` и папку `assets` на любой статический хостинг, сохранив структуру.

## Что внутри

- `index.html` — семь блоков оригинала, включая footer; весь текст редактируется здесь.
- `assets/styles.css` — адаптивная вёрстка, отдельные карточки, телефон, золотые кнопки и анимации.
- `assets/app.js` — появление элементов при прокрутке, обработка кнопок и доступное диалоговое окно.
- `assets/config.js` — четыре адреса оплаты, записи и видео.
- `assets/backgrounds/01…07.png` — семь восстановленных фонов в полном разрешении, без встроенного текста и кнопок.
- `assets/backgrounds/01…07.webp` — оптимизированные изображения, используемые сайтом (всего около 650 КБ).
- `assets/fonts` — локальные Montserrat и Caveat с лицензиями OFL.
- `reference` — оригиналы семи PNG, сохранённый HTML, промпты и материалы проверки; для публикации не требуется.

## Подключение кнопок

На исходной странице ссылки оплаты, записи и видео равны `#`. Реальных адресов там нет. Укажите полные HTTPS-адреса в `assets/config.js`:

```js
window.CLUB_LINKS = Object.freeze({
  light: 'https://ваш-домен/оплата-старт',
  master: 'https://ваш-домен/оплата-мастер',
  personal: 'https://t.me/ваш_аккаунт',
  video: 'https://ваш-домен/видео'
});
```

До заполнения адресов кнопки показывают честное сообщение о недоступности. Оплата, Telegram-бот и видео не имитируются. После заполнения кнопки открывают указанные адреса в текущей вкладке. При отключённом JavaScript доступны весь контент, навигация и текстовый fallback; подключённые через config.js адреса требуют JavaScript.

## Визуальное соответствие

Сохранены порядок, тексты тарифов и реквизитов, цены, чёрно-золотая палитра, сюжет фотографий и композиция исходника. Фоны восстановлены встроенным imagegen отдельно для каждого исходного PNG. Это генеративная реконструкция: детали фотографий под удалёнными надписями могут отличаться от оригинала. Шрифты подобраны визуально (исходные шрифтовые файлы на странице отсутствуют).

Текст, цены, кнопки, рамки карточек и телефон — HTML/CSS. Фотографии и фактура — отдельные растровые фоны. Сообщение внутри телефона является примером, скрытая персональная ссылка не выдумывается. На мобильных экранах высота карточек зависит от текста, поэтому пропорции длинных исходных PNG намеренно не фиксируются.

Анимации: спокойное появление первого экрана, однократный fade/translate при прокрутке, мягкий hover/press кнопок. Нет бесконечного параллакса и обработчика каждого события scroll. Учитывается `prefers-reduced-motion`; без JS контент остаётся видимым.

## Проверка

Проверено в Chromium на ширинах 320, 390, 768 и 1440 px: нет горизонтального переполнения, локальные шрифты загружаются, JS-ошибок нет. Дополнительно проверены ленивая загрузка коллажа при прокрутке, появление текста, диалоги оплаты и видео, закрытие Escape, режим без JavaScript и отключённые анимации. Скриншоты находятся в `reference`.
